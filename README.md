# World Happiness Report (2016) — Data Analysis & Interactive Dashboard

## Project Overview

This project analyses the 2016 World Happiness Report dataset to explore relationships between national happiness scores and economic, health, and social factors across 157 countries.

The project was completed as part of an IBM Coursera guided practice exercise.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Plotly
- Jupyter Notebook
- Generative AI for code assistance

## Project Workflow

1. **Data Cleaning:** Identified and handled missing values and corrected data types.
2. **Exploratory Data Analysis:** Examined happiness scores and their relationships with GDP, health, family, freedom, trust, and generosity.
3. **Data Visualisation:** Created bar charts, scatter plots, and a geographical map.
4. **Dashboard Development:** Combined interactive visualisations into an HTML dashboard.
5. **Data Storytelling:** Summarised important findings and their implications.

## Key Findings

- GDP contribution had the strongest positive correlation with Happiness Score (r = 0.790).
- Health (r = 0.759) and family support (r = 0.739) also showed strong positive correlations.
- Generosity showed a relatively weak positive correlation (r = 0.157).
- Regional differences were evident, particularly between Western Europe and Sub-Saharan Africa.

These findings demonstrate associations, not causal relationships.
